# Make your own View-Master website in 4 steps

Turn your photos, writing, and favorite links into an interactive vintage picture viewer. You can start with this project's code and let Codex help you personalize it.

[Try Anna's version](https://anna-view-master.vercel.app/) · [Get the code](https://github.com/annanoellerinke/anna-view-master)

## 1. Open Codex

On your computer, follow the [official setup guide](https://learn.chatgpt.com/docs/quickstart) to install the desktop app and sign in with your ChatGPT account. Select **Codex** from the app's ChatGPT dropdown, then start a new chat. If you already use Codex, just open a new chat.

## 2. Give it the project and this prompt

Copy and paste:

> Help me make my own interactive View-Master website using the code at https://github.com/annanoellerinke/anna-view-master. Create a separate copy for me. Keep the vintage viewer, swappable reels, red advance lever, and photo preview. Replace Anna's name, photos, links, and branding with mine, including the lettering on the viewer. Ask me for my reel themes, images, and exact destinations before building. Explain the plan in plain language, then show me a working preview. I'm a beginner, so handle the files and code and explain anything you need me to do. Wait for my approval before publishing.

## 3. Make it yours

Give Codex your name and the three collections you want people to explore. For example: your writing, your business, and your Instagram posts. Supply the photos or covers and the link each picture should open. Use your own images and branding.

Review the preview and ask for changes in normal language: “Make the dial red,” “Keep vertical photos tall,” or “Move this label below the reels.” Keep going until it feels like you.

For Instagram, ask for each picture to open its specific post. Start with a saved collection; automatic Instagram updates need a separate account connection and aren't enabled just by adding your username.

## 4. Publish it and test it on your phone

When you're happy, tell Codex:

> Publish this approved version on Vercel and save the code in my own GitHub repository. Walk me through any accounts or approvals you need. Give me the live website link and the GitHub link, and check that everything works.

GitHub stores the code; Vercel puts the website online. Complete the sign-in and approval prompts as needed.

Open the live link on your computer and phone. Switch reels, advance through the pictures, and tap the images to check their destinations. Then add your new website to your bio!
